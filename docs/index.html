Featured Projects

MSc Dissertation: Digital Health Engagement in NHS England

A service evaluation of 15,571 My Way Diabetes users in three NHS localities. I benchmarked users against the National Diabetes Audit and modelled time to disengagement with a stratified Cox regression. Users disengaged almost immediately (median 0.5 days), and the most deprived and older users were under-represented.

SACCO Performance Dashboard (Power BI)

A nine-page Power BI report for a savings and credit co-operative, tracking membership, loan disbursement, exits, complaints and savings against targets across six branches. DAX target and variance measures, gauges and slicers. A view-only, anonymised client work sample.

DHIS2 Data Pipeline

Built a reproducible R pipeline to extract, clean and structure family planning service data from DHIS2 using the khisr package. Parsed composite DHIS2 category columns, mapped 61 data elements to their FP method groups, calculated Couple Years of Protection (CYP), and exported analysis-ready data for 59 service delivery points across Malawi.

Risk Factors for Arthritis: Statistical Modelling

Investigated associations between arthritis and risk factors (sex, age, BMI, physical activity) using 360,000 observations from the CDC BRFSS survey. Applied chi-square tests, Wilcoxon rank-sum tests, relative risk ratios and logistic regression. Females had 54% higher adjusted odds of arthritis (OR = 1.54, 95% CI: 1.52–1.57).

Predicting Diabetes with Machine Learning

Built logistic regression and random forest classifiers on NHANES data using tidymodels. Random forest improved sensitivity for positive diabetes cases from 4% to 34%, with a ROC-AUC of 0.89, showing better discrimination between diabetic and non-diabetic participants.

Data Cleaning and Imputation

A full data cleaning pipeline on deliberately messed Iris data (using the messy package). I standardised 68 “messed” species strings, converted data types, assessed missingness with naniar and imputed missing values with random forest (missForest). The imputed distributions closely matched the original data.

Interactive Shiny Dashboard

A live, interactive R Shiny application deployed on shinyapps.io for real-time project tracking and faster decisions.
